# Masalsı Pırıltı

Masalsı Pırıltı, Programlamaya Giriş dersi vizesi için hazırladığım bir Türk masalları derlemesidir. Sitede sekiz masal bulunur. Ziyaretçiler masalları başlıklarına göre arayabilir ve seçtikleri masalı sayfa içinde okuyabilir.

## Proje bağlantıları

- [Canlı siteyi aç](https://ireem1622-ops.github.io/masalsi-pirilti/)
- [Sitenin kaynak kodunu incele](./index.html)

## Teknik yapı

Sayfanın HTML yapısı, CSS stilleri ve JavaScript kodu `index.html` dosyasında yer alır. JavaScript, masal aramasını ve okuma ekranını yönetir.
